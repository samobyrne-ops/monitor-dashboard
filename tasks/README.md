# Task Context Files

This directory contains task context files generated by Monitor (the autonomous heartbeat agent).

## Format

Each file follows this naming convention:
```
task-{source}-{timestamp}-{sequence}.md
```

Example: `task-slack-1716249600-001.md`

## Structure

```markdown
# Task: {one-line summary}

## Source
- Type: slack | gmail | meeting | manual
- Link: {permalink to original message/email}
- Detected: {ISO timestamp}
- Priority: high | medium | low

## Original Context
{full text of the original message, email, or transcript excerpt}
{includes sender, channel/thread context}

## Agent Analysis
{Monitor's triage reasoning}
{relevant context from Memory/ or Context/ files}
{any data pulled from Databricks/Looker/Salesforce}
{research findings if applicable}

## What's Needed
{clear description of what Sam needs to do, decide, or review}
{deadline if applicable}

## Suggested Approach
{Monitor's recommendation for how to handle this}
{draft reply if applicable}

## Resolution
{filled in when the task is completed}
{what was done, by whom, when}
{link to sent message/email if applicable}
```

## How It Works

1. **Monitor creates**: When the heartbeat detects a new item that needs attention, it creates a task file here with all available context.

2. **Dashboard links here**: The Monitor dashboard has an "Open in Cursor" button on each card. Clicking it opens an interactive Cursor session with the prompt: `Read tasks/task-{id}.md and continue working on this task`

3. **Cursor picks up**: The interactive agent reads the task file, loads the full context (Memory/, Context/, rules), and continues where Monitor left off. You get full MCP access, can query data, draft messages, etc.

4. **Resolution written**: When the task is complete, the interactive session writes the resolution to the task file and updates the Google Sheet (status = done).

## Cleanup

Task files for completed items are retained for 30 days (for reference and feedback loop analysis), then archived to `tasks/archive/`.

## Manual Tasks

You can also create task files manually:
```bash
touch tasks/task-manual-$(date +%s)-001.md
```

Then add a row to the Google Sheet with `source: manual` and the task file path. Monitor will pick it up on the next heartbeat.
